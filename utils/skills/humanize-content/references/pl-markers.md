# Markery AI i sztuczności — język polski

Pełny katalog wzorców, które zdradzają tekst wygenerowany przez AI albo
przekalkowany z angielskiego. SKILL.md ma skrót — tu jest reszta, z przykładami.

Traktuj to jako **repertuar, nie listę kontrolną**. Poprawiaj to, co realnie
poprawia tekst; wzorzec, który w danym miejscu niesie sens, zostaw. Mechaniczne
przejechanie po wszystkich sekcjach daje tekst poprawny i martwy.

## 1. Zaimki i dzierżawcze (pro-drop)

Polski pomija podmiot wynikający z odmiany i zaimek dzierżawczy, gdy
przynależność jest oczywista. Nadmiar „ja / my / twój / swój / nasz" to kalka
angielskiego „I / we / your / our" i marker numer jeden w polskim copy z AI.

| Sztucznie | Naturalnie |
|---|---|
| **Ja** uważam, że to zadziała | Uważam, że to zadziała |
| **My** oferujemy wdrożenia | Oferujemy wdrożenia |
| Umyj **swoje** ręce | Umyj ręce |
| Zadbaj o **swoje** zdrowie i chroń **swoje** dane | Zadbaj o zdrowie i chroń dane |
| Wypełnij **swój** formularz i podaj **swój** adres | Wypełnij formularz i podaj adres |
| **Nasz** produkt pomoże **Twojej** firmie zwiększyć **Twoje** przychody | Nasz produkt pomoże firmie zwiększyć przychody |
| Oni zdecydowali, że **oni** wdrożą | Zdecydowali, że wdrożą |

**Kiedy zostawić:** realny kontrast („to **mój** problem, nie **twój**"),
bezpośredni zwrot w mailu albo CTA („Dziękujemy za **Twoją** wiadomość"),
ujednoznacznienie właściciela. W copy pisanym do jednej osoby „Twój system",
„Twoje biuro" bywa świadomą zasadą głosu marki — sprawdź konfig projektu.
Zasada: tnij **redundancję**, nie każdy zaimek.

## 2. Urzędowe i „ciężkie" czasowniki

| Sztucznie | Naturalnie |
|---|---|
| Firma **posiada** trzy oddziały | Firma ma trzy oddziały |
| **dokonać** rezerwacji / zakupu / wyboru / zmian | zarezerwować / kupić / wybrać / zmienić |
| **realizować** płatność / dostawę | zapłacić / dostarczać |
| **przeprowadzić** analizę / przegląd | przeanalizować / przejrzeć |
| **dysponować** budżetem | mieć budżet (zostaw, gdy naprawdę o dyspozycję chodzi) |
| To **stanowi** problem | To jest problem / To problem |
| Aktualizacja **ma miejsce** co tydzień | Aktualizujemy co tydzień |
| **ulec** awarii | zepsuć się / stanąć |
| **pozostawać** w gotowości | być gotowym |
| **znajduje zastosowanie** w | używa się go w / przydaje się w |

## 3. Nominalizacja

Polski oddycha czasownikami. AI piętrzy rzeczowniki odczasownikowe (-anie,
-enie, -cja) i wychodzi z tego styl protokołu z urzędu.

| Sztucznie | Naturalnie |
|---|---|
| w celu zwiększenia sprzedaży | żeby zwiększyć sprzedaż |
| poprzez wykorzystanie / przy użyciu narzędzia | dzięki narzędziu / korzystając z narzędzia |
| dokonujemy weryfikacji danych | weryfikujemy dane |
| umożliwia przeprowadzenie analizy | pozwala przeanalizować |
| w przypadku wystąpienia błędu | gdy pojawi się błąd |
| celem realizacji zamówienia | żeby zrealizować zamówienie |
| dokonanie wdrożenia systemu | wdrożenie systemu / wdrożyć system |
| proces podejmowania decyzji | decydowanie |

## 4. Łańcuchy dopełniaczy

Silny i rzadko zauważany marker: trzy albo więcej rzeczowników w dopełniaczu
jeden po drugim. Zdanie jest gramatyczne, ale czytelnik gubi się w drugim
ogniwie, bo musi trzymać w głowie cały łańcuch, zanim dojdzie do sensu.

- „proces optymalizacji wydajności systemu zarządzania treścią" →
  „optymalizujemy wydajność CMS-a"
- „możliwość konfiguracji parametrów integracji systemu płatności" →
  „skonfigurujesz integrację z płatnościami"
- „w celu zapewnienia bezpieczeństwa przetwarzania danych klientów" →
  „żeby bezpiecznie przetwarzać dane klientów"
- „narzędzie do automatyzacji obsługi zgłoszeń serwisowych" → zwykle OK (dwa
  ogniwa), ale sprawdź, czy nie da się prościej: „narzędzie, które automatyzuje
  zgłoszenia serwisowe"

Sposób na rozbicie: zamień pierwsze ogniwo z powrotem na czasownik i wskaż
wykonawcę. Zwykle łańcuch rozpada się sam.

## 5. Doklejone imiesłowy

Odpowiednik angielskiego trailing „-ing" clause i tak samo mocny tell. AI
domyka zdanie imiesłowem, który dorzuca korzyść, ale nie niesie informacji.

- „System synchronizuje dane co godzinę, **zapewniając pełną aktualność**." →
  „System synchronizuje dane co godzinę." (reszta to powtórzenie)
- „Wdrażamy w dwa tygodnie, **pozwalając zespołowi skupić się na sprzedaży**." →
  „Wdrażamy w dwa tygodnie. Zespół przez ten czas sprzedaje normalnie."
- „…, **umożliwiając** / **gwarantując** / **dając** / **oferując** …" — ten sam
  wzorzec, ta sama poprawka: albo wytnij, albo zrób z tego osobne zdanie z
  konkretem.

Uwaga na **błąd nierównoważności podmiotu** — imiesłów musi mieć ten sam
wykonawca co orzeczenie: „Wchodząc do pokoju, zadzwonił telefon" (telefon nie
wchodził) → „Kiedy wszedłem do pokoju, zadzwonił telefon".

Osobno: nagromadzone otwarcia imiesłowowe („Chcąc zwiększyć sprzedaż, warto…",
„Mając na uwadze…", „Biorąc pod uwagę…") to styl urzędowy. Jedno na tekst.

## 6. Kalki frazeologiczne z angielskiego

| Kalka | Poprawnie |
|---|---|
| w oparciu o | na podstawie / opierając się na |
| być w stanie („jesteśmy w stanie dostarczyć") | możemy dostarczyć / dostarczymy |
| adresować problem | zająć się problemem / rozwiązać / odpowiedzieć na |
| aplikacja wspiera format PDF | obsługuje format PDF |
| dostarczać wartość | przynosić korzyści / dawać efekty / być przydatnym |
| narzędzie **dla** automatyzacji | narzędzie **do** automatyzacji |
| na końcu dnia | ostatecznie / koniec końców / w gruncie rzeczy |
| nie wahaj się skontaktować | śmiało napisz / chętnie pomożemy |
| dedykowany (= specjalny, osobny) | przeznaczony / osobny / własny (zostaw utarte: „serwer dedykowany") |
| generyczny | zwykły / ogólny / standardowy |
| zlokalizowany (= located) | położony / znajdujący się / mieszczący się |
| w temacie X | w sprawie X / co do X |
| posiadać wiedzę / doświadczenie | znać się na / mieć doświadczenie |
| idziemy z opcją A (go with) | wybieramy opcję A |
| „mieć sens" w co drugim zdaniu | różnicuj: to się opłaca / to logiczne / warto |
| zaadresować potrzeby | odpowiedzieć na potrzeby |
| na bazie / bazując na | na podstawie |

## 7. Słowa-wytrychy i kolokacje

Słowa, które AI wsadza wszędzie, aż przestają cokolwiek znaczyć. Tnij albo
zastępuj konkretem:

- „kluczowy", „istotny", „znaczący", „znaczny" — przy każdym rzeczowniku;
- „odpowiedni", „właściwy", „dany", „określony" — zwykle puste;
- „efektywnie", „skutecznie", „kompleksowo", „profesjonalnie" — przysłówki-wata;
- „rozwiązanie" jako zamiennik wszystkiego (produkt, usługa, narzędzie, system)
  → nazwij rzecz po imieniu;
- „funkcjonalność" → zwykle wystarczy „funkcja";
- „pozwala / umożliwia" w kółko → różnicuj: „dzięki temu", „z X zrobisz",
  „X robi Y".

**Kolokacje.** Osobny, subtelniejszy problem: AI dobiera słowo poprawne
znaczeniowo, ale nieużywane w tym połączeniu. Efekt to zdanie, którego nie da
się wskazać palcem jako błędnego, a mimo to brzmi obco.

- „**silna** jakość obsługi" → „wysoka jakość obsługi"
- „**głęboka** wiedza o produkcie" → „dogłębna znajomość produktu"
- „**prowadzić** decyzję" → „podjąć decyzję"
- „**budować** zaufanie klientów" — OK; „**konstruować** zaufanie" — nie
- „**mocne** doświadczenie" → „duże doświadczenie" / „solidne doświadczenie"

Test: czy to połączenie słyszałeś kiedyś poza tym tekstem? Jeśli nie — zamień
na utarte.

## 8. Waciki marketingowe i puste otwarcia

- **Puste przymiotniki:** innowacyjny, nowoczesny, dynamiczny, kompleksowy,
  zaawansowany, rewolucyjny, przełomowy, najwyższej jakości, szyty na miarę,
  szeroki wachlarz, bogata gama, dedykowane rozwiązania → wytnij albo zastąp
  konkretem: co dokładnie, dla kogo, z jakim efektem.
- **Puste otwarcia:** „W dzisiejszych czasach…", „W dzisiejszym świecie…",
  „W erze cyfrowej…", „Żyjemy w czasach, gdy…", „Warto zaznaczyć, że…",
  „Warto pamiętać, że…", „Należy podkreślić, że…", „Nie da się ukryć, że…",
  „Jak powszechnie wiadomo…" → najczęściej do usunięcia bez żadnej straty.
- **Domykacze-frazesy:** „Mamy nadzieję, że ten artykuł okazał się pomocny",
  „Podsumowując, warto stwierdzić, że…", „Jak widać, możliwości są ogromne" →
  tnij albo zamień na konkretną puentę.
- **Konstrukcja „nie tylko X, ale (także) Y"** i „zarówno X, jak i Y" częściej
  niż raz na tekst → rozpisz prościej.

## 9. Pleonazmy i redundancja

- „okres czasu" → „okres" albo „czas"
- „cofać się do tyłu" → „cofać się"; „wracać z powrotem" → „wracać"
- „kontynuować dalej" → „kontynuować"
- „wzajemna współpraca" → „współpraca"
- „w miesiącu maju" → „w maju"; „w dniu wczorajszym" → „wczoraj"
- „akwen wodny" → „akwen"; „fakt autentyczny" → „fakt"
- „w pełni kompletny", „całkowicie darmowy" → „kompletny", „darmowy"
- „mała chwilka", „drobny szczegół" → „chwila", „szczegół"

## 10. Anglicyzmy a odbiorca

Anglicyzm przyjęty w branży czytelnika zostaje; poza nią — spolszczaj. Nie
chodzi o purystyczne czyszczenie, tylko o to, czy odbiorca zna to słowo.

- **Odbiorca z IT:** „deployment", „feature", „roadmapa", „lead", „pipeline",
  „backlog" — zostawiasz, spolszczanie brzmiałoby dziwacznie.
- **Odbiorca spoza IT** (właściciel biura, przewoźnik, dyrektor operacyjny):
  „per stanowisko" → „osobno dla każdego stanowiska"; „na roadmapie" →
  „w planach rozwoju"; „onboarding" → „wdrożenie zespołu"; „call" → „rozmowa";
  „dashboard" → „panel"; „insighty" → „wnioski".

Test: czy odbiorca użyłby tego słowa sam, w rozmowie przy kawie?

## 11. Szyk wyrazów

- **Przymiotnik klasyfikujący idzie PO rzeczowniku** (nazywa typ, rodzaj,
  kategorię): „polski język" → „język polski"; „elektroniczna poczta" → „poczta
  elektroniczna"; „graficzna karta" → „karta graficzna"; „osobowy samochód" →
  „samochód osobowy"; „dochodowy podatek" → „podatek dochodowy".
  Przymiotnik **oceniający** zostaje przed rzeczownikiem: „piękny widok",
  „szybki system", „dobra decyzja".
- **Nowa i ważna informacja na końcu zdania** (pozycja rematu). Polski układa
  zdanie: znane → nowe, a nie sztywno SVO jak angielski. Zdanie „brzmi
  przetłumaczone"? Zwykle wystarczy przesunąć puentę na koniec:
  „Nowa funkcja eksportu jest już dostępna" → „Udostępniliśmy nową funkcję
  eksportu".
- **Klityki „się", „by" i krótkie zaimki** (mi, ci, go, mu, cię) nie stoją na
  początku ani na końcu zdania — ciążą do drugiej pozycji: „Warto zastanowić
  **się** nad tym" → „Warto **się** nad tym zastanowić"; „Aby zarejestrować
  **się**, kliknij…" → „Aby **się** zarejestrować, kliknij…".
- **„nie" tuż przed czasownikiem**, którego dotyczy przeczenie.
- **Łańcuchy „który"** — trzy zdania podrzędne z „który" w jednym akapicie to
  składnia protokołu. Rozbij na osobne zdania albo zamień jedno na imiesłów
  przymiotnikowy.

## 12. Strona bierna i formy bezosobowe

Polski lubi stronę czynną oraz formy bezosobowe na „-no/-to" i „się".
Nadużyta strona bierna („zostało wykonane", „jest realizowane przez") to kalka.

- „Zamówienie **zostało zrealizowane** przez nasz zespół" → „Zrealizowaliśmy
  zamówienie"
- „Raport **jest generowany** automatycznie" → „Raport generuje się
  automatycznie" / „System generuje raport automatycznie"
- „Decyzja **została podjęta**" → „Podjęto decyzję"

Zostaw stronę bierną, gdy wykonawca jest nieistotny albo celowo przemilczany —
to jej właściwe zastosowanie, nie błąd.

## 13. Rytm, łączniki i struktura

- **Monotonia długości zdań** — AI pisze ciąg zdań o podobnej długości i
  budowie. Różnicuj: krótkie obok dłuższego. To najczęściej decyduje o wrażeniu
  naturalności, mocniej niż jakakolwiek poprawka słownikowa.
- **Powtarzane łączniki** — „Ponadto", „Co więcej", „Dodatkowo", „Również",
  „Warto dodać", „Niewątpliwie", „Z pewnością", „Podsumowując". Maksymalnie
  raz; zwykle da się usunąć i zacząć zdanie od rzeczy.
- **Powtarzane otwarcia** — każdy akapit zaczynający się tak samo (od nazwy
  produktu, od „To", od podmiotu) → przełam kolejność albo zacznij od okolicznika.
- **Trójki** („szybko, tanio i wygodnie") — raz to rytm, w co drugim akapicie to
  sygnatura. Zredukuj do dwóch elementów albo rozbij.
- **Symetryczne pary „X. Ale Y."** powtórzone kilka razy — ulubiona kadencja
  modeli. Zostaw jedną.
- **Jednakowa długość akapitów** (np. wszystkie po trzy zdania) — ten sam tell
  co monotonia zdań, piętro wyżej.
- **Listy zamiast prozy i odwrotnie** — nie zmieniaj formy, jeśli oryginał
  używa jej celowo. Ale gdy AI rozbiło na punkty coś, co jest płynną myślą,
  a użytkownik nie wymaga listy, możesz to scalić.

## 14. Spójność

- **Rejestr** — jeden poziom formalności w całym tekście. AI miesza („Szanowni
  Państwo" + „spoko"). Wyrównaj do rejestru, który dominuje.
- **Formy adresatywne** — nie skacz między „Pan/Pani", „Państwo" i „Ty".
  Trzymaj jedną w obrębie tekstu.
- **Aspekt czasownika** (dokonany/niedokonany) — pilnuj spójności w opisie tej
  samej czynności i logiki następstwa zdań.
- **Liczba i osoba** — „klient może… ich konta" → uzgodnij („klienci mogą…
  swoje konta" albo „klient może… swoje konto").
- **Terminologia** — jedna nazwa na jedną rzecz w całym tekście. Synonimizacja
  na siłę („panel / kokpit / dashboard" wymiennie) myli czytelnika.

## 15. Interpunkcja

### Przecinek

Przed spójnikiem wprowadzającym zdanie podrzędne — **obowiązkowo**: że, żeby,
aby, który, jaki, gdzie, gdy, kiedy, jeśli, jeżeli, ponieważ, bo, dlatego że,
choć, chociaż, mimo że, tak że, dopóki, zanim.

- „Myślę że to zadziała" → „Myślę, że to zadziała"
- „To rozwiązanie które wybraliśmy" → „To rozwiązanie, które wybraliśmy"

Zdanie podrzędne w środku oddziela się przecinkami z obu stron: „Plik, który
wczoraj wysłałeś, jest uszkodzony".

**Bez przecinka oksfordzkiego** przed pojedynczym i, oraz, lub, albo, ani, czy,
bądź: „jabłka, gruszki, i śliwki" → „jabłka, gruszki i śliwki". Przecinek wraca,
gdy spójnik jest powtórzony („i tu, i tam", „ani ja, ani ty") albo gdy zamyka
wtrącenie („Zobacz, co potrafi, i sprawdź cennik").

**Przed a, ale, lecz, jednak, natomiast, więc, toteż, zatem** — zwykle stoi:
„Chciałem przyjść, ale nie zdążyłem".

**Imiesłów na „-ąc"** oddziela się przecinkiem: „Wracając do domu, spotkałem
Anię"; „Zrobił to, nie pytając nikogo".

**Bez przecinka** w porównaniu bez orzeczenia: „tak dobry jak zespół".

### Cudzysłów

Polski podstawowy: **„ "** (otwierający dolny `„`, zamykający górny `"`). Nie
angielski `" "` ani `" "`. Wewnątrz cudzysłowu: ostrokątny **» «** albo
definicyjny **‚ '** — „Kliknij »Zapisz«, żeby zachować zmiany".

### Myślnik, półpauza, dywiz

Trzy różne znaki, mylone nagminnie:

- **Dywiz** `-` — w wyrazach złożonych i nazwach: „biało-czerwony",
  „polsko-niemiecki", „Bielsko-Biała", „e-mail", „2-osobowy". Bez spacji.
- **Półpauza** `–` — w zakresach: „strony 10–20", „lata 2020–2024",
  „godz. 9–17", „trasa Warszawa–Kraków". Bez spacji.
- **Pauza** `—` — myślnik zdaniowy we wtrąceniu i w miejsce opuszczonego
  orzeczenia, **ze spacjami**: „To jest proste — wystarczy kliknąć";
  „Ja jestem inżynierem, on — handlowcem".

Poprawianie zakresu: „2020-2024" → „2020–2024". Politykę gęstości pauzy opisuje
SKILL.md — pauza jest poprawna, ale w tekstach z AI występuje kilka razy za
często.

### Wielokropek

Jeden znak `…`, nie trzy kropki `...`. Po wielokropku nie stawia się dodatkowej
kropki na końcu zdania.

## 16. Liczby, daty, jednostki

- **Separator dziesiętny to przecinek**: „3.5" → „3,5"; „19.99 zł" → „19,99 zł".
- **Separator tysięcy to spacja** (najlepiej nierozdzielająca), nie przecinek:
  „1,000,000" → „1 000 000".
- **Procent bez spacji**: „20 %" → „20%". Jednostki miar **ze spacją**: „5 kg",
  „10 zł", „100 km", „24 h".
- **Zakresy**: „od 10 do 20" albo „10–20". Nie mieszaj: „od 10-20" jest błędne.
- **Daty**: „15 marca 2024" (miesiąc małą literą) albo „15.03.2024" /
  „2024-03-15". Nie „15-go marca".
- **Godziny**: „o 9:00", „godz. 14.30", „od 9 do 17" albo „9–17".

## 17. Kapitalizacja i typografia

- **Nagłówki i tytuły to sentence case** — wielka tylko pierwsza litera i nazwy
  własne, nie angielski Title Case: „Jak Zwiększyć Sprzedaż w Sklepie" →
  „Jak zwiększyć sprzedaż w sklepie".
- **Małą literą**: dni tygodnia („wtorek"), miesiące („listopad"), nazwy języków
  i przymiotniki od narodowości („polski", „niemiecki"), „internet", kierunki
  świata („północ") poza nazwami geopolitycznymi.
- **Wielką literą**: rzeczowniki nazw narodowości („Polak", „Niemka"), nazwy
  własne, święta („Boże Narodzenie"). Mieszkańcy miast małą: „warszawiak".
- **Zwroty grzecznościowe** w bezpośrednim zwrocie (list, email, CTA) wielką
  literą: „Ty", „Ciebie", „Twój", „Państwo", „Wam". W reklamie do anonimowego
  ogółu bywa małą — dostosuj do konwencji tekstu, ale rób to spójnie.
- **Spacje**: brak przed `. , ; : ? !`, spacja po nich. Skróty z kropką: „np.",
  „itp.", „itd.", „tzn.", „tj.", „m.in.", „ok.", „godz." („nr" bez kropki).
- **Listy wypunktowane**: punkty-równoważniki małą literą, bez kropki (albo ze
  średnikami, ostatni z kropką); punkty będące pełnymi zdaniami wielką literą i
  z kropką. Nie mieszaj obu konwencji w jednej liście.
